# 滴答记 · DiDa Ji

2026-06-26 README 更新 from Codex

滴答记是一个手机优先的个人饮食与身体记录 Web App，用来轻量记录每天吃了什么、身体感受如何，以及大便情况。它适合日常自我观察，也方便之后导出给医生、AI 或自己复盘。

## 主要功能

- 饮食记录：支持早餐、午餐、晚餐、加餐，记录后会出现轻量鼓励语。
- 大便情况：基于布里斯托大便分类法简化为 5 类，用图标快速记录。
- 今日感受：每天记录一次身体状态。
- 日历回顾：按日期查看饮食、感受和大便情况。
- 彩蛋反馈：连续记录和大便情况累计记录会触发小彩蛋。
- Markdown 导出：导出一段时间内的饮食与身体记录。
- 账号同步：登录后可将本机记录与云端合并。
- 手机桌面入口：部署后可添加到手机桌面，像小 App 一样打开。

## 使用方式

打开线上地址即可使用；本地预览时打开 `index.html` 或 `dida-ji.html`。手机浏览器打开后，可以添加到主屏幕。

## 当前入口

- `index.html`：入口跳转页。
- `dida-ji.html`：真实应用页面。
