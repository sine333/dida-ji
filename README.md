# 滴答记 · DiDa Ji

一个手机优先的个人饮食记录 Web App。打开 `index.html` 或 `dida-ji.html` 即可使用，数据保存在当前浏览器的 localStorage 中。

## 现在怎么用

1. 电脑本地：直接打开 `index.html`。
2. 手机使用：部署到 Vercel 后，用手机浏览器打开 Vercel 地址，并可添加到主屏幕。
3. 数据隐私：记录只存在打开它的那个浏览器里，Vercel 不会保存饮食数据。

## 功能

- 今日饮食记录
- 饮食记录删除
- 今日感受单选保存
- 月历回顾
- Markdown 导出
- 连续 3 天、7 天、30 天和累计 100 条记录的里程碑动效
- 本地鼓励语库
- PWA 基础缓存，部署后可像小 App 一样从主屏幕打开
