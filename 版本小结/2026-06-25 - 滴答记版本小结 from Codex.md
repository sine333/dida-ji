## v2026-06-25-supabase-sync

### 需求

- 在保留本地可用的前提下，加入 Supabase 云同步能力。
- 目标是让记录未来可以跟账号走，支持多端同步。
- 为未来接入模型 API 或 agent 分析保留数据基础。

### 实际改动

- 在 `dida-ji.html` 中加入 Supabase 项目地址和 publishable key。
- 增加邮箱 magic link 登录入口。
- 增加登录状态、手动同步、退出登录能力。
- 增加云端同步逻辑：
  - 本地饮食记录同步到 `records`。
  - 今日感受同步到 `daily_moods`。
  - 删除记录采用软删除标记，避免多端被旧数据恢复。
- 新增 Supabase 数据库建表 SQL：
  - `records`
  - `daily_moods`
  - `analysis_reports`
  - RLS 规则限制用户只能访问自己的数据。
- 新增 Supabase 后续配置说明文档。

### 验证情况

- 本地脚本语法检查通过。
- 用户已在 Supabase SQL Editor 执行建表 SQL，返回 `Success. No rows returned`。
- 用户已提供 Supabase Project URL 和 publishable key，并已写入应用。

## v2026-06-25-mobile-sync-fix

### 需求

- 用户在手机上记录两条后，手机本机没有显示，但电脑登录后可以看到。
- 说明云端写入成功，但手机端展示或刷新存在问题。

### 实际改动

- 将页面中固定的 `TODAY` 常量改为动态 `getTodayKey()`。
- 保存记录、今日视图、日历高亮、导出范围、连续天数统计都改为动态取当天日期。
- 增加同步队列保护：
  - 如果同步中又产生新记录，会在当前同步结束后自动补跑一次。
- 增加页面重新可见和窗口聚焦后的自动同步：
  - 手机从后台切回页面时，会尝试同步一次。
- `sw.js` 缓存版本从 `v4` 升到 `v5`。
- `sw.js` 改成网络优先策略，降低手机一直读取旧页面缓存的概率。

### 验证情况

- `dida-ji.html` 脚本语法检查通过。
- `sw.js` 语法检查通过。

  - 已登录时显示账号、同步状态、同步按钮、退出按钮。
- 同步面板增加“收起”按钮。
- `sw.js` 缓存版本从 `v5` 升到 `v6`。
